# Disharo / PathFinder

A React career-exploration demo built with Vite.

The free Class 10 mini-test uses the 50 supplied questions in `src/data/class10Questions.json`. Each answer adds one interest point to its mapped stream (PCM, PCB, Commerce, Arts/Law, or Creative/Fashion). Results rank all five and group paths within 10% of the highest score so students can explore multiple close matches. This is a simple reflection tool, not a validated assessment or a prediction.

## Requirements

- Git
- Node.js 18 or newer (includes npm)

## Clone and run

```powershell
git clone https://github.com/sngv17/PathFinder.git
cd PathFinder
npm install
npm run dev
```

Open the local URL printed by Vite (by default, <http://localhost:5173>). Stop the development server with `Ctrl+C`. You only need to run `npm install` after cloning or when dependencies change.

To create and preview a production build:

```powershell
npm run build
npm run preview
```

The sign-up/login screens, profile flow, opportunity previews, and Class 10 mini-test are front-end demonstrations. They do not authenticate users, store credentials, send notifications, or process payments. Connect an identity provider and secure backend before using real accounts or personal data.
